# Тесты для BooksCollector

В проекте реализованы автотесты для проверки работы класса `BooksCollector`.

## Покрытые методы

### add_new_book
- добавление новой книги
- книга не добавляется повторно
- книга не добавляется при невалидном имени (пустая строка, более 40 символов)

### set_book_genre
- установка жанра для существующей книги
- жанр не устанавливается, если он не входит в список допустимых

### get_book_genre
- возвращает корректный жанр книги

### get_books_with_specific_genre
- возвращает только книги с выбранным жанром

### get_books_for_children
- возвращает книги без возрастного ограничения

### add_book_in_favorites
- добавление книги в избранное
- книга не добавляется повторно
- нельзя добавить книгу, которой нет в списке книг

### delete_book_from_favorites
- удаление книги из избранного
- попытка удалить несуществующую книгу не влияет на список

### get_list_of_favorites_books
- возвращает актуальный список избранных книг

## Дополнительно
- Использована параметризация тестов:
  - в тесте `test_add_new_book_not_add_invalid_book` — для проверки невалидных названий книг (пустая строка и строка длиной более 40 символов)
  - в тесте `test_get_books_with_specific_genre_returns_correct_count` — для проверки количества книг в зависимости от выбранного жанра
